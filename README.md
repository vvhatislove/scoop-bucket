# Scoop bucket

A [Scoop](https://scoop.sh) bucket with the apps of
[vvhatislove](https://github.com/vvhatislove).

```powershell
scoop bucket add vvhatislove https://github.com/vvhatislove/scoop-bucket
scoop install trayjuice
```

| App | What it is |
|---|---|
| [TrayJuice](https://github.com/vvhatislove/TrayJuice) | Battery levels of wireless headsets, mice and gamepads on the Windows taskbar |

Update with `scoop update trayjuice`; quit TrayJuice from its tray icon
first, because Windows cannot replace a running program.

Manifests are updated automatically within a few hours of a new release.
